# 🖥️ GenAI Security Gateway - Systems & Monitoring Infrastructure

The official monitoring and management dashboard for the GenAI Security Gateway ecosystem. Designed with a modern, dark-themed SOC (Security Operations Center) console interface to provide real-time visibility over AI threat mitigation.

---

## ✨ Features

* **Live Security Telemetry:** Real-time visualization of total requests processed, prompt injection attempts blocked, and data loss prevention metrics.
* **SOC-Console UI:** Modern, responsive dark-mode interface optimized for rapid incident monitoring.
* **Resilient API Integration:** Seamlessly communicates with the backend security gateway via containerized internal networking, featuring built-in graceful fallback handling for offline states.

---

## 🛠️ Tech Stack

* **Frontend:** Python, Flask, HTML5, CSS3, Jinja2
* **Networking & Integration:** RESTful APIs, Docker Network

---

## 🚀 Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/nir968/genAI-security-web.git
   cd genAI-security-web
   ```

2. **Install dependencies:**
   ```bash
    pip install -r requirements.txt
   ```

3. **Run the dashboard:**
   ```bash
   python  app.py
   ```
3. **Access the interface:**
    Open your browser and navigate to: http://localhost:5001
